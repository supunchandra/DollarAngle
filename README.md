# DollarAngle

Production-oriented Astro foundation for **DollarAngle — A smarter angle on your money.**

## Editorial preview and approval

All launch articles are drafts. Preview locally with `SHOW_DRAFTS=true`. Production hides drafts unless explicitly approved.

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
SITE_URL=https://your-final-domain.com npm run build
```

See `LAUNCH-CONTENT.md` for the launch library and approval checklist.
